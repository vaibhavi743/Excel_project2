# Excel_project2

## 📌 Project Overview

PR. 2 Analyzer is an Excel-based data analysis project designed to analyze customer sales data and extract meaningful business insights.

This project focuses on sales performance, customer purchasing behavior, profit analysis, and data visualization using Microsoft Excel.

## 🎯 Project Objectives

* Analyze customer sales and profit data.
* Identify high-value customers.
* Understand sales performance across regions and product categories.
* Perform statistical analysis and linear regression.
* Create meaningful charts and dashboards.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Excel Formulas & Functions
* Conditional Formatting
* What-If Analysis
* Data Analysis ToolPak
* Pivot Tables & Charts

## 📂 Dataset Information

The dataset contains customer sales information with the following columns:

* Customer_ID
* Customer_Name
* Region
* Product_Category
* Sales
* Quantity
* Discount
* Order_Date
* Profit
* Total Purchase
* Estimated Profit

## 📈 Key Features

### 1. Conditional Formatting

* Highlighted the Top 10 customers based on Total Purchase.
* Applied visual formatting to identify important sales values.

### 2. What-If Analysis

* Analyzed the impact of different discount rates on estimated profit.
* Used Data Tables to compare different business scenarios.

### 3. Linear Regression

* Performed linear regression to analyze the relationship between Sales and Profit.
* Used Excel Data Analysis ToolPak.

### 4. Descriptive Statistics

* Calculated statistical measures to understand the dataset.
* Analyzed mean, median, standard deviation, and other statistical values.

### 5. Histogram Analysis

* Created a histogram to understand the distribution of sales data.

### 6. Data Visualization

* Created charts to represent sales and profit insights.
* Used Pivot Tables and Pivot Charts for summarized analysis.

### 7. High-Value Customer Analysis

* Identified valuable customers based on their total purchases.
* Used Excel formulas and lookup functions.
